"Size" can be chosen again after resizing the window

With the window set to open at the video's size, resizing it by hand and then picking "Size" again in the menu did nothing — you had to switch to another option and back. Picking it again now returns the window to the video's size. Choosing a window option in the right-click menu also closes the menu, so it is no longer cut off when the window shrinks under it.
