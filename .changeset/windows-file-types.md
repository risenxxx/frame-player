Frame Player in Windows' Default apps, with each file type its own

On Windows the player now appears under Settings → Apps → Default apps, where it can be chosen for each video and audio type. Video formats are no longer lumped together as one "Video file" type: an MKV is an "MKV video file", an MP4 an "MP4 video file", and Explorer sorts them apart. Music files such as MP3 and FLAC can be opened with the player too — it is offered for them, without taking them from the music player you already use. On macOS the player is offered for audio files in "Open With" as well.
