Report a problem with one button

Settings → Report a problem collects what a bug report needs — the version, the system, the settings, the player's logs and mpv's — and shows all of it before anything happens. Paths, file names, links, network addresses, device names and identifiers are replaced first; you can then copy the report, save it to a file, or open a new issue on GitHub and attach it. A verbose log can be switched on next to it to record the conversation with a TV in detail: turn it on, reproduce the problem, collect the report. It switches itself off when the player restarts.
