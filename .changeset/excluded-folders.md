Excluded folders also cover files handed over in unusual ways

A file from an excluded folder or drive could still be added to Continue watching when another program opened it under a different spelling of its path: a path relative to that program's folder, Windows' long path form, or a file link. Such paths are now recognised as the same place, so the exclusion applies to them too, and a file opened with a relative path while the player was already running now opens the right file.
