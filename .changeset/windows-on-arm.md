Frame Player runs natively on Windows on ARM

Laptops with an ARM processor, such as those with Snapdragon chips, get an installer and a portable download of their own, built for ARM rather than run through Windows' emulation of x64, and it updates itself like the x64 version. The website offers it next to the Windows button and picks it by itself in browsers that say which processor they run on. If you installed the x64 version on such a laptop before, run the ARM installer: it removes the x64 version first, and your settings and watch history stay. An x64 copy left as it is keeps working and updating as before.
