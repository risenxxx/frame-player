Subtitles in a font of your own

Settings → Subtitles has a Fonts section: add TTF, OTF, TTC or OTC files, click one to use it for plain-text subtitles (or type the name of a font installed in the system), and remove them again. The list shows each font by its name rather than its file name, both subtitle lines use it, subtitles that ask for an added font by name find it too, and every change applies at once, without a restart.
