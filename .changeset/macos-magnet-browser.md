Magnet links clicked in a browser open in the player on macOS

Frame Player can now be the app that opens magnet links on a Mac. A link clicked in a browser brings up the player's link box with the magnet already in it — one press of Open (or Enter) starts it, so a web page cannot interrupt what you are watching or start a download on its own. If you already use another torrent app for magnet links, it stays the default until you change it.
