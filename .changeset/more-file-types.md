More video and audio formats open with Frame Player

RealMedia (.rm, .rmvb), ASF, DivX, F4V, MXF, DV, WTV, Ogg Media, MPEG-2 video, HD DVD video and 3GPP2 files can now be opened from Explorer or Finder and set as the player's in Default apps, and so can audiobooks (.m4b) and more audio formats such as .mp2, Musepack, TTA, TAK, AMR, Core Audio, DSD and RealAudio. The same formats are now picked up when the rest of a folder is queued and listed in a torrent, and the video ones are offered in the Open dialog.
