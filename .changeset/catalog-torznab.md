The catalog works with Jackett and Prowlarr

The catalog now searches releases through a Torznab server of your own: paste the address from Jackett or Prowlarr and its API key in the torrent settings. The player no longer ships with a release source; until you set one, the catalog shows descriptions and says which setting is missing, with a button that takes you to it. Releases from private trackers open from their torrent files.
