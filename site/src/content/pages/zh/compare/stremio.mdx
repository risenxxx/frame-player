很多人安装 [Stremio](https://www.stremio.com/)，是为了不必先下载就能看种子里的电影。它自称是一个现代媒体中心，核心形态是插件：你安装插件，由插件提供你浏览的片库和你播放的视频源，Stremio 表示它自己不提供任何内容。[Frame Player](/zh) 从另一端走到了相近的地方。它是一个基于 mpv、适用于 Windows 和 macOS 的视频播放器，能播放你给它的任何文件；它还能边下边播种子、浏览电影和剧集片库、把它们投屏到电视，这一切都不需要额外安装任何东西。

## 相同之处

**桌面端的引擎**。Stremio 当前的 Windows 外壳程序是[开源的](https://github.com/Stremio/stremio-shell-ng)，通过 mpv 播放视频，而 Frame Player 也基于这个引擎。格式支持、硬件解码和 HDR 出自同一处。

**种子还没下完就能看**。两者都能在打开磁力链接或 `.torrent` 文件几秒后开始播放，不必等整个文件下完。

**海报、分季和“继续观看”一栏**。两者都从电影和剧集的片库出发，而不是一串文件名，也都会记住你停在了哪里。

## Frame Player 更进一步的地方

**它是播放你已有文件的播放器**。电影不必在片库里，Frame Player 也能播放。双击文件、拖入文件夹、粘贴链接：这一集打开后，文件夹中的其余部分按自然顺序成为播放队列（第 2 集在第 10 集之前），并从你停下的地方继续，带上你选的配音和字幕，按语言而不是音轨编号记住。种子和片库是播放器额外能做的事，而不是它存在的理由。

**资源只有一个来源，而且是你自己的**。片库通过项目自己的代理从 TMDB 获取海报、本地化片名和分季信息，所以播放器不带任何 API 密钥；一部电影的资源列表来自你自己运行的 Torznab 服务器，即 Jackett 或 Prowlarr。播放器不自带任何来源，也不推荐任何来源。资源按画质排序，其次是动态范围，最后是做种数，你选中的资源以种子方式打开，支持继续播放，整季作为播放队列。

**种子边下边播，而且告诉你它在做什么**。播放位置前方紧挨着的文件块优先下载，不做任何预测性下载：打开整季种子中的第三集，就只下载第三集。已经在磁盘上的部分会在进度条上标出，读数会区分“没有用户”和“用户很慢”，上传默认关闭。网络出问题时，连接加密可以绕过识别 BitTorrent 的过滤，SOCKS5 代理可以绕过按目标地址的封锁，而“**种子出口路由**”可以让种子流量走你选择的网络接口（[原理](/zh/torrent-streaming)）。

**电视上不需要装应用**。除了 Chromecast，Frame Player 还能把电影发送到 DLNA 电视自带的播放器，从 Mac 还能发送到 AirPlay 接收器。在你选择电视之前，每台电视都会说明这个文件在它上面能直接播放、需要快速重新封装，还是无法播放；画面从不重新编码（[投屏原理](/zh/cast-to-tv)）。

**一起看是播放器的一部分**。一个六位代码就能让身在别处的朋友停在同一帧上。种子会被每个人的播放器自动接收，每个人看的都是自己那份全画质的拷贝；房间只传递时间轴，别的什么也不传（[原理](/zh/watch-together)）。

**一个好播放器该有的其他功能**。精确到那一帧的进度条预览、按文件自身指纹搜索的字幕、根据文件章节跳过片头、双向逐帧、裁剪黑边、神经网络超分辨率，以及始终置顶的迷你播放器。

**没有账号，只有一个功能会涉及你看什么**。Frame Player 不需要登录。片库是唯一会发送你搜索内容的功能，发送给元数据代理和你自己的 Torznab 服务器，所以设置里有关闭它的开关，其他一切不依赖它也能正常使用。

## Stremio 更合适的情况

<Note>
  **如果你想在手机、电视和电脑上使用同一个媒体库**，请使用 Stremio。Frame Player 只支持 Windows 和 Mac。
</Note>

- **每块屏幕**。除了 Windows 和 macOS，Stremio 还有 Android、Android TV、多个智能电视平台、Linux 和网页版应用。Frame Player 只能通过从电脑投屏来使用电视。
- **同步的媒体库**。有了账号，Stremio 会在你所有的设备之间同步媒体库和观看进度。Frame Player 把这两者都保存在一台电脑上。
- **插件生态**。插件可以引入 Frame Player 没有对应功能的来源：社区插件可以连接 debrid 服务，桌面端的 Stremio 5 还新增了 Usenet、FTP 和压缩包内的视频作为视频源。
- **资源无需任何设置**。很多人装一个现成的插件，几分钟后就在看了。Frame Player 的片库需要你先自己运行一个 Torznab 服务器，才能列出资源。
- **Intel Mac 和 Linux**。Frame Player 的 macOS 版适用于 Apple Silicon，也没有 Linux 版。

很多人会两个都用：电视和手机上用 Stremio，电脑上用 Frame Player，用来播放电脑上已有的文件和你在电脑上打开的种子。
