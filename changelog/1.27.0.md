### New

- **A portable version for Windows.** There is now a second Windows download: an archive you unpack wherever you like — a USB stick, a folder on another drive — which keeps its settings, watch history, previews and downloads in its own folder instead of in your user profile. Move the folder and the player moves with it, remembering every position and every chosen audio track. It updates itself the same way the installed version does, by replacing its own files. Two things are worth knowing: it registers itself for video files and for watch-together invitation links, because Windows offers no way to do that from inside a folder — there is a switch in Settings if you would rather it did not, and turning it off puts back whatever was there before — and if the Microsoft Edge WebView2 runtime is missing from the computer, the player installs it on first run, though it is already present on essentially every Windows 10 and 11.
