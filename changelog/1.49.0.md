### New

- **Subtitles in a font of your own.** Settings → Subtitles has a Fonts section: add TTF, OTF, TTC or OTC files, click one to use it for plain-text subtitles (or type the name of a font installed in the system), and remove them again. The list shows each font by its name rather than its file name, both subtitle lines use it, subtitles that ask for an added font by name find it too, and every change applies at once, without a restart.
- **Frame Player in Windows' Default apps, with each file type its own.** On Windows the player now appears under Settings → Apps → Default apps, where it can be chosen for each video and audio type. Video formats are no longer lumped together as one "Video file" type: an MKV is an "MKV video file", an MP4 an "MP4 video file", and Explorer sorts them apart. Music files such as MP3 and FLAC can be opened with the player too — it is offered for them, without taking them from the music player you already use. On macOS the player is offered for audio files in "Open With" as well.

### Improvements and fixes

- **The logo takes you back to the start screen.** With a file open, clicking the Frame Player logo in the title bar closes it and returns to the start screen.
