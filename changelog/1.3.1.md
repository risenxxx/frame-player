### New

- **Show torrent files.** Each torrent on the start screen can now reveal its folder in Explorer or Finder.

### Improvements and fixes

- **Torrents take only the space they use.** On Windows, opening a season used to reserve the full size of every episode on disk straight away. Files now grow only as they are downloaded.
- **Watch together alone.** A film no longer plays slightly fast when you are the only one in a room, and creating a room from the start screen no longer says it is waiting for you.
- **More precise pauses in a room.** Pausing or changing speed now shares the exact position, so others stop on the same frame rather than slightly behind.
