### Improvements and fixes

- **Opens normally on macOS.** The macOS app and disk image are signed with an Apple Developer ID and notarized, so macOS opens it like any other app instead of asking you to allow it in System Settings. The Windows installer is not signed yet and still shows a SmartScreen warning on first run.
