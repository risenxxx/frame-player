### New

- **The installer can set up a portable copy too.** The installer now offers a checkbox on the page where you choose the folder: keep settings and watch history in that folder rather than in your user profile. It is the same thing the portable archive does, so you no longer have to unpack a zip by hand to get it — and re-running the installer over such a folder arrives with the box already ticked, so leaving things as they are takes no thought. Uninstalling removes that data only if you ask it to, exactly as it treats the settings it keeps in your profile. A copy set up this way still opens video files and invitation links the way any installed copy does, so the switch for that is gone from its settings — the installer handles it, and uninstalling undoes it.
