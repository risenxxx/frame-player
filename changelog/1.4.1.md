### Improvements and fixes

- **Torrent folder setting.** The folder now appears as a field with "Choose" and "Reset" inside it, and a long path is shortened from the start so the folder name stays visible.
- **Delete menu on the start screen.** Deleting a torrent now opens a small menu beside its row instead of expanding the row, so the list no longer moves under the pointer while you choose.
