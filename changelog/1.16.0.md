### New

- **Brightness and color.** A new Picture panel in the context menu has sliders for brightness, contrast, saturation and gamma. While you drag one, the menus turn see-through so you can judge the picture. Double-click a slider to reset it.
- **Apply to a file, a playlist or all files.** Each adjustment can be kept for this file only, for every file in its folder or torrent, or for all files. The narrowest one wins, and if a wider choice would overwrite existing values, the player asks which to keep. Defaults for all files can also be set under Settings, Video.
- **Picture hotkeys.** New actions raise and lower each of the four values and reset them all. They have no keys by default except C, which opens the picture settings.

### Improvements and fixes

- **Crop follows the playlist.** The crop mode now applies to the whole playlist, while Auto still measures the bars of each file separately, so episodes share the choice without inheriting each other's bars.
- **Auto crop for torrents.** Auto crop now works on a torrent that is still downloading, using the part already on disk. If too little has arrived, the player says so.
