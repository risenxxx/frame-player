### Improvements and fixes

- **Catalog loading.** Posters and releases now show placeholders while they load instead of an empty panel.
- **Clear when unavailable.** When the catalog service is down, the panel says so rather than failing silently.
- **Default release search.** When you have not set your own release search service, the default is now provided by the catalog service, so it can change without installing a new version. Your own setting always takes priority.
- **TMDB attribution.** The catalog now shows the TMDB logo alongside its notice.
