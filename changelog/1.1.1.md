### Improvements and fixes

- **Magnet links open quickly.** A magnet link now asks its own trackers for peers straight away, so a link that could time out after 90 seconds now opens in about a second.
- **Trackers work everywhere.** Many trackers refused the player's requests or sent replies it could not read, so the peers they listed were lost. Both problems are fixed on every platform.
- **Going back to the start screen.** Closing a torrent now stops its download and removes the download readout from the start screen right away.
- **Link dialog starts empty.** Opening the link dialog no longer shows the previous link and old error, and the dialog closes once a torrent's file list appears.
