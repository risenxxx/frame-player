### Improvements and fixes

- **The player starts on Windows computers without a Vulkan driver.** On a virtual machine, a computer whose graphics driver is not installed, or one with an older graphics card, the player stopped at "Could not start mpv" and told you to look for files in a folder that does not exist in an installed copy. It now brings the one missing system component with it, and if the player still cannot start, the message names the file Windows could not load and why.
