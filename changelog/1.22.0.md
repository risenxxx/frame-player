### New

- **The catalog works with Jackett and Prowlarr.** The catalog now searches releases through a Torznab server of your own: paste the address from Jackett or Prowlarr and its API key in the torrent settings. The player no longer ships with a release source; until you set one, the catalog shows descriptions and says which setting is missing, with a button that takes you to it. Releases from private trackers open from their torrent files.

### Improvements and fixes

- **Resizing the window no longer leaves a see-through edge on Windows.** Dragging a window edge used to show a strip along it that the picture had not reached yet — the desktop, or a smeared copy of the frame — because the video layer was a step behind the window. It now keeps up with the edge, and a fast drag leaves nothing behind.
