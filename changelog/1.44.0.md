### New

- **Seek steps of any length.** Beside the preset steps for the arrows, J and L and the wheel, you can type any number of seconds from 1 to 600.
- **New shortcuts, and a search for them.** Speed back to 1× (=), show the time (T), open the settings (Ctrl+,), close the file (Ctrl+W) and quit (Ctrl+Q) are now keys you can reassign like the rest. A search box at the top of the shortcuts list finds an action by name, by group or by the key it is on.
- **Playback speed in round steps, and on the wheel.** The speed keys now step through 1.25, 1.5, 1.75, 2 and so on rather than multiplying, which gave 1.56× and 1.95×. The speed is always shown on the control bar: scroll over it to change it, click it for 1×. The wheel with Alt held changes the speed anywhere over the video; the key can be changed or turned off in Settings → Playback.
- **Subtitle opacity, and subtitles that stay put.** Settings → Subtitles has sliders for the opacity of the text and of the box or shadow behind it, keeping any colour you set yourself. Subtitles moving up while the control bar is on screen can now be turned off there too.
- **Time left on the control bar.** Click the length at the right end of the seekbar to see how much is left instead, counted at the current speed: at 2× a minute of film shows as thirty seconds. The choice is remembered.

### Improvements and fixes

- **Clear only the Continue watching list.** Settings → General can now empty the Continue watching list on its own, keeping track choices, delays and picture settings, instead of clearing the whole history.
- **Controls stay usable on damaged files.** Opening a damaged or half-downloaded file, especially several in a row from a queue, could make the control bar and the window buttons disappear and come back over and over. They now return within a second whatever the file does.
- **Ctrl, Alt and Shift no longer bring up the controls.** Pressing a modifier on its own, or any key that does nothing, left the control bar over the picture. Now only keys that do something show it.
- **Media info can be selected and copied.** The text in the media info panel can be selected, and a Copy button puts all of it on the clipboard.
- **A note when the next file starts.** When a folder or a torrent moves on to the next file by itself, its name now shows briefly on screen.
- **A clearer message when a file will not open.** A file that cannot be opened is now named in the message, which says it may be damaged, still downloading or in an unsupported format, instead of suggesting a website problem.
