### New

- **The window can open at the video's own size.** "Window to video" now has three choices: Off, Aspect (the window keeps its size and takes the video's shape, as before) and Size, which opens the window at the video's resolution, the way mpv does. With Size, a 720p file opens in a 1280×720 window and a 4K file in a window as large as the screen allows. A size you pick by hand carries over to the next episode of the same resolution. It is in Settings → Window, in the right-click menu under Window and in the View menu on macOS.

### Improvements and fixes

- **The player says once that it was installed.** On its very first start, a new installation sends one request to the Frame Player site saying whether it runs on Windows or macOS, so the site can show how many people have installed it. Nothing else is sent: no identifier, no files, nothing about what you watch, and the request is never repeated. Installations from before this release do not send it.
