### Improvements and fixes

- **The button that clears the Continue watching list is the size of the others.** It was larger than every other button in the settings.
- **The replay button stays in the middle of the end screen.** At the end of the first file of a queue, with only a next file to offer, the replay button and the next file's card were centred together, pushing the button off to one side. It now stays in the middle whether there is a previous file, a next one or both.
- **The note about the next file now shows.** The name of the next file, shown when a folder or a torrent moves on by itself, appeared while the screen was still dark and was gone before the new file was on screen. It now appears once the next file is playing.
