### New

- **Updates on Windows no longer run an installer.** The player now downloads the new version and replaces its own files, then reopens the window where you left off. There is no installer window to wait for, nothing is uninstalled first, and the video you were watching comes back at the same frame. If an update cannot be applied that way — because the program is installed somewhere it is not allowed to write, or because that release moves files around — it falls back to the installer, as before. macOS is unchanged; it has always worked this way.
