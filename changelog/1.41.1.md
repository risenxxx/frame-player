### Improvements and fixes

- **About is in the right-click menu.** The version, the website and the source code were at the very bottom of the settings, where few people looked. The right-click menu now has an About item that opens straight onto them.
- **The window can be moved while the settings are open.** Dragging the title bar with the settings or another dialog open used to close the dialog first and only move the window on the second try. It now moves the window and leaves the dialog where it was.
- **Windows updates download once again.** On some installations every update downloaded twice — the progress bar on the update button filled up, then started over — because a file left behind by an older version made the player give up on its quick update and fetch the full installer as well. Such leftovers no longer get in the way, so the update downloads once and is applied in place.
