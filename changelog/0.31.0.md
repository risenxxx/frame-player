### Improvements and fixes

- **Start screen appears complete.** The list of unfinished videos is on screen at its final size when the window opens, instead of appearing a moment later and pushing the rest down.
- **Delays that return to zero.** An audio or subtitle delay dialled back to zero is now treated as zero: the reset button turns off and the file no longer remembers a tiny leftover delay.
- **Excluded folders on Windows.** A folder excluded from the watch history now matches its files regardless of which way the slashes in the path point.
