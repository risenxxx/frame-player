### Improvements and fixes

- **Excluded folders also cover files handed over in unusual ways.** A file from an excluded folder or drive could still be added to Continue watching when another program opened it under a different spelling of its path: a path relative to that program's folder, Windows' long path form, or a file link. Such paths are now recognised as the same place, so the exclusion applies to them too, and a file opened with a relative path while the player was already running now opens the right file.
- **More video and audio formats open with Frame Player.** RealMedia (.rm, .rmvb), ASF, DivX, F4V, MXF, DV, WTV, Ogg Media, MPEG-2 video, HD DVD video and 3GPP2 files can now be opened from Explorer or Finder and set as the player's in Default apps, and so can audiobooks (.m4b) and more audio formats such as .mp2, Musepack, TTA, TAK, AMR, Core Audio, DSD and RealAudio. The same formats are now picked up when the rest of a folder is queued and listed in a torrent, and the video ones are offered in the Open dialog.
