### Improvements and fixes

- **No false "Next episode".** On the last chapter of a single file with repeat turned on, the skip button offered a "Next episode" that restarted the same file. It now appears only when there really is a different file next.
- **Queue position stays correct.** The player now recovers its place in the queue if it ever loses track of it, which kept the end screen and auto-advance pointing at the right file.
